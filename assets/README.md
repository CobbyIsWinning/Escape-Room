# Library scenery

## Cloudy awakening

`cloudy-opening.mp4` and its fallback `cloudy-opening.jpg` come from the
[user-selected Pinterest Pin](https://www.pinterest.com/pin/574209021262662947/).
The public Pin supplies a 20-second starry-sky video viewed through trees.
The opening plays the clip muted beneath a mist overlay for six seconds, then
fades into the library. The video and preview image are stored as downloaded.
`cloudy-opening-source.json` records the original Pin and media URLs. The source
is also linked in the in-app artwork credits. Reduced-motion mode skips the opening.

## Active Pinterest scenes

The four `pinterest-*.jpg` files come from publicly displayed previews in the
[user-provided ancient library search](https://www.pinterest.com/search/pins/?q=ancient%20library&rs=typed).
They are served by Pinterest's image CDN and stored locally for both app versions.
`pinterest-sources.json` records each displayed preview URL, downloaded image URL,
and the search page. Original artist names and individual Pin URLs were not
provided in the signed-out preview cards; no artist attribution is invented.
The in-app “Library artwork · Pinterest” expander links the search and image sources.

| Scene | Local file |
| --- | --- |
| The veiled rotunda | `pinterest-candlelit.jpg` |
| The whispering gallery | `pinterest-gallery.jpg` |
| The enchanted archive | `pinterest-archive.jpg` |
| The wizard’s study | `pinterest-study.jpg` |

The image files are preserved as downloaded, without retouching or watermark removal.
